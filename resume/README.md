# Resume

| File | Format |
|---|---|
| [`Alvin_Piquero_Resume_Business_Analyst.pdf`](./Alvin_Piquero_Resume_Business_Analyst.pdf) | PDF, for reading and sharing |
| [`Alvin_Piquero_Resume_Business_Analyst.docx`](./Alvin_Piquero_Resume_Business_Analyst.docx) | Word, editable source |

The resume targets business analysis and business systems analysis roles. Its text is
mirrored in [`MASTER_RESUME.md`](./MASTER_RESUME.md), so the repository carries a
searchable, diffable copy of every claim on the resume.

When a fact changes, edit the Word file first, export a new PDF, then update
`MASTER_RESUME.md` and its change log to match.

See the [top-level README](../README.md) and [`case-studies/`](../case-studies) for the
work behind the resume.
