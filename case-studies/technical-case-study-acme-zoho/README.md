# Technical Case Study: ACME Home Repairs (Zoho)

[`Technical_Case_Study_ACME_Home_Repairs_Zoho.pdf`](./Technical_Case_Study_ACME_Home_Repairs_Zoho.pdf)

A written solution-design case study for a fictional client, ACME Home Repairs, whose
manual job logging, scheduling and follow-up are replaced by a Zoho-based workflow.

The two-page document maps each pain point to a Zoho module, lays out the data flow,
identifies one custom bottleneck with a fallback and a control, lists the discovery
questions that must be answered before go-live, and ends with a short kickoff email to
the client. It states what must be verified in the documentation rather than asserting it.
